# Markdown Spec Test Files

このディレクトリには、e2eテストで使用されるMarkdownファイルが格納されています。

## ファイル命名規則

- `{番号}-{説明}.md` の形式で命名
- 番号は2桁（01, 02, ...）
- 説明は英語でケバブケース

## テストファイル一覧

| ファイル名 | 説明 |
|-----------|------|
| `01-basic-title.md` | 基本的なタイトルスライドとコンテンツスライド |
| `02-complex-layouts.md` | 複数のレイアウトタイプを含む複雑な構成 |
| `03-grid-only.md` | グリッドレイアウトのみ（2x2, 3x2） |
| `04-left-right-only.md` | 左右レイアウトのみ（1:1, 2:1, 1:3） |
| `05-default-only.md` | デフォルトレイアウトのみ（1〜3セクション） |
| `11-wiki-pattern.md` | WikiPattern（左3節＋右の SVG 図解）。takeaway あり／なしと、節を宣言順と違う順で書いた場合 |

## 新しいテストケースの追加方法

1. このディレクトリに新しい `.md` ファイルを追加
2. ファイル名は `{次の番号}-{説明}.md` の形式にする
3. `e2e.test.ts` が自動的に検出してテストを実行する
4. このREADMEを更新して新しいファイルを記録する
