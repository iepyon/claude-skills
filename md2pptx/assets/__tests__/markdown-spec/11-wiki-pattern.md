## Seed Note
<!--pattern-->
### いつ・なにが困るか
A thought arrives while doing something else, and the moment to write it down never quite comes.

**Waiting for a tidy moment means the note never gets written.**
A blank line splits the section into two paragraphs; the second one carries no heading.

### そこで
Write one sentence. Grow it later.

## Sections Out Of Order
<!--pattern-->
### そこで
Sections are stacked in the order the vocabulary declares them, not the order written.

### いつ・なにが困るか
The two sections are written そこで → いつ・なにが困るか。

**Reading order must not depend on authoring order.**
