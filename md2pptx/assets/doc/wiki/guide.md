# リンクで辿るスライド

ページめくりだけではない、もう一つの読み方

---

## 何ができるか
<!--id:概要-->
<!--icon-cols-->

### ホバーで覗く
<!--icon:mi:visibility-->
移動せずに行き先を確かめる。

### リンクで飛ぶ
<!--icon:mi:link-->
戻るボタンで来た道を戻れる。

### 逆から辿る
<!--icon:mi:swap_horiz-->
参照している側の一覧が出る。

---

## 書き方
<!--id:書き方-->
<!--table-->

| 書くもの | 意味 |
| --- | --- |
| `[[種ノート]]` | 内部リンク。表示は ID そのまま |
| `[[patterns-human/剪定]]` | デッキをまたぐ明示的なリンク |
| `[ラベル](https://…)` | 外部リンク |
| `<!--id:foo-->` | スライドに ID を付ける |

<!--takeaway-->
角括弧の中を縦棒で区切ると表示テキストを指定できる。ID を省くと見出しから自動生成される

---

## リンクの解決順
<!--id:解決順-->
<!--numbered-list:circle-->

### deck/slide の形で書かれている
そのまま その ID を指す。デッキをまたぐときの確実な書き方。

### 同じデッキに同じ ID がある
自分のデッキを先に探す。ふだんは短い ID だけ書けばよい。

### サイト全体でちょうど1つだけ一致する
デッキが違っても、名前が一意なら繋がる。

### それ以外は未解決
複数一致しても勝手に選ばない。サイドバーに一覧が出る。

<!--takeaway-->
黙って先頭を選ぶと、デッキが増えた瞬間にリンク先が変わってしまう

---

## 操作
<!--id:操作-->
<!--grid:2x2-->

### ← →
デッキ内を順に送る。従来のページめくりと同じ。

### Shift + ← →
デッキの境界を越えて送る。

### リンクにホバー
行き先を縮小表示。プレビューの中のリンクも辿れる。

### Esc
プレビューを閉じる。

---

## 何に使えるか
<!--id:使いどころ-->
### パターン集
互いに参照し合う知識は、順番に並べると関係が消える。
実例は [[intro-human/育てる理由|第1部]] から辿れる。

### 育っていくメモ
書き足すたびに構造が変わるものは、目次を固定できない。
[[索引は後から]] がまさにその話。

### 発表と参照の両立
発表では順に送り、後から読む人はリンクで回遊する。
1つの成果物で両方を満たせる。これが [[収穫]]。
