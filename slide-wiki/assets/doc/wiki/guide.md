# リンクで辿るスライド

ページめくりだけではない、もう一つの読み方

---

## 何ができるか
<!--id:概要-->
<!--icon-cols-->

### ホバーで覗く
<!--icon:mi:visibility-->
移動せずに行き先を確かめる。

### リンクで飛ぶ
<!--icon:mi:link-->
戻るボタンで来た道を戻れる。

### 逆から辿る
<!--icon:mi:swap_horiz-->
このスライドを指している側の一覧が出る。

---

## 書き方
<!--id:書き方-->
<!--table-->

| 書くもの | 意味 |
| --- | --- |
| `[[種ノート]]` | 同じサイト内へのリンク。表示は ID そのまま |
| `[[patterns-wiki/剪定]]` | 別のデッキのスライドを名指しするリンク |
| `[ラベル](https://…)` | 外部リンク |
| `<!--id:foo-->` | スライドに ID を付ける |

<!--takeaway-->
角括弧の中を縦棒で区切ると表示テキストを指定できる。ID を省くと見出しから自動生成される

---

## リンクの解決順
<!--id:解決順-->
<!--numbered-list:circle-->

### デッキ名/スライド名 と書いてある
その ID をそのまま指す。別のデッキを指すときの確実な書き方。

### 同じデッキに同じ ID がある
自分のデッキを先に探す。ふだんは短い ID だけ書けばよい。

### サイト全体でちょうど1つだけ一致する
デッキが違っても、その名前がサイトに1つなら繋がる。

### それ以外は未解決
候補が2つ以上あるときは勝手に選ばない。サイドバーに一覧が出る。

<!--takeaway-->
黙って先頭を選ぶと、デッキが増えた瞬間にリンク先が変わってしまう

---

## 操作
<!--id:操作-->
<!--grid:2x2-->

### ← →
順に送る。デッキの境界も越えるので、サイト全体を通しで読める。

### スライドの左右端をクリック
同じ送りをタップでも。端のリンクはリンクとして働く。

### リンクにホバー
行き先を縮小表示。プレビューの中のリンクも辿れる。Esc で閉じる。

### 戻る
辿ってきた道を1つ戻る。ブラウザの戻ると同じもの。

---

## 何に使えるか
<!--id:使いどころ-->
### パターン集
互いに参照し合う知識は、順番に並べると関係が消える。
実例は [[intro-wiki/育てる理由|第1部]] から辿れる。

### 育っていくメモ
書き足すたびに構造が変わるものは、目次を固定できない。
[[けもの道]] がまさにその話。

### 発表と参照の両立
発表では順に送り、後から読む人はリンクを辿って回る。
1つの成果物で両方を満たせる。これが [[収穫]] というパターンである。
