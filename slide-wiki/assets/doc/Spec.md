## スライドの制限
- 各スライド全体で240文字以内。見出し記号は除外。
- ネスト箇条書き不可。1階層のみ対応。
- レイアウト指定可能。left:N、right:M、grid:RxC形式。

## 番号リスト（circle）
<!--numbered-list:circle-->
### 仮説を立てる
観察事実から「〜ならば〜だろう」の形で仮説を記述する。
### 検証計画を作る
仮説ごとにインタビュー質問・反証シグナルを設計する。
### インタビュー実施
5名以上に実施し、回答パターンを記録する。
### 結果を分析する
仮説が支持されたか反証されたかを判定する。
### 次の仮説へ進む
学びを反映し、新たな仮説サイクルを開始する。

<!--takeaway-->
仮説検証は1週間スプリントで回すこと

---

## 注意点・アンチパターン（bar）
<!--numbered-list:bar-->
### AI盲信
AIの出力を検証なしに採用してはいけない。必ず人間が確認する。
### 確証バイアス
都合のよい情報だけ集めて仮説を正当化しない。反証を探す。
### 回答者否定
仮説が外れたとき「対象者が間違い」と結論づけない。
### スコープ肥大
一度に多くの仮説を検証しようとせず、1つずつ絞る。

<!--takeaway-->
これらのアンチパターンを避けることが仮説検証の質を高める

interface User {
  id: number
  name: string
  email: string
}

function createUser(data: Partial<User>): User {
  return {
    id: Date.now(),
    ...data
  } as User
}
